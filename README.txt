Talent4LY — النسخة النهائية

طريقة التشغيل
1. فكّي ضغط الحزمة كاملة.
2. في VS Code اختاري File > Open Folder وافتحي مجلد Talent4LY.
3. افتحي index.html في المتصفح، أو من خلال Live Server إن كان مثبتاً عندك.

الملفات
index.html: محتوى الصفحة والأقسام والهيدر.
style.css: الألوان والتنسيق والتجاوب مع الشاشات.
script.js: قائمة الموبايل وربط أزرار الانضمام برابط التسجيل.
assets/ministry-logo.png: شعار الوزارة.
assets/bot-logo.png: شعار المجتمع.

هذه الملفات تعمل معاً. احتفظي بمجلد assets بجانب ملفات الأكواد.
لا تحتاج هذه النسخة إلى npm أو تثبيت مكتبات.

تفعيل التسجيل
افتحي script.js، وفي أعلى الملف ضعي رابط نموذج التسجيل الفعلي مكان القيمة الفارغة:
registrationUrl: "",

النسخة الحالية صفحة تعريفية ولا تحفظ بيانات المستخدمين.
طالما لم يضف رابط التسجيل، تعرض الأزرار رسالة «رابط التسجيل غير متاح حالياً».

تعديل الألوان
متغيرات الألوان موجودة داخل :root في بداية style.css:
الرئيسي: #163e35
الأزرار والتمييز: #00D8F6
الخلفية: #F8F9FA
النصوص: #222222

التجاوب
شعار الوزارة يمين الهيدر، واسم وشعار Talent4LY يسار، والروابط في المنتصف.
تتحول الروابط إلى قائمة قابلة للفتح عند عرض 1100px أو أقل.
عند تغيير هذا الحد، عدّليه في style.css وscript.js معاً.
